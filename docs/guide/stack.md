# Stack Technique

- **Backend** : Laravel 12
- **Frontend** : React avec Inertia.js
- **Authentification** : Laravel Breeze
- **Base de données** : PostgreSQL
- **Containerisation** : Docker
- **Styling** : Tailwind CSS
- **Icons** : [Feather Icons](https://feathericons.com/)
- **Build frontend** : Vite
